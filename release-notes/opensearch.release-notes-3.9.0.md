## Version 3.9.0 Release Notes

Compatible with OpenSearch and OpenSearch Dashboards version 3.9.0

### Features

* Add DELETE task API for removing stored completed task results ([#21727](https://github.com/opensearch-project/OpenSearch/pull/21727))
* Add deployment drain and finish APIs for zero-downtime node deployments ([#21448](https://github.com/opensearch-project/OpenSearch/pull/21448))
* Add adaptive per-action concurrency limiting module with Vegas, Gradient2, and AIMD algorithms ([#22312](https://github.com/opensearch-project/OpenSearch/pull/22312))
* Add virtual thread-per-task executor support to ThreadPool ([#22485](https://github.com/opensearch-project/OpenSearch/pull/22485))
* Add extensible payload decoder framework for pull-based ingestion ([#22364](https://github.com/opensearch-project/OpenSearch/pull/22364))
* Add plugin SPI for dynamic field-type inference and dynamic-template types ([#22607](https://github.com/opensearch-project/OpenSearch/pull/22607))
* Add pluggable PrimaryOperationPolicy to EngineConfig for cross-cluster replication ([#22886](https://github.com/opensearch-project/OpenSearch/pull/22886))
* Add object-store fencing token for remote store primary term validation ([#22774](https://github.com/opensearch-project/OpenSearch/pull/22774))
* Auto-restore remote store primaries on node loss when no valid copy survives ([#22904](https://github.com/opensearch-project/OpenSearch/pull/22904))
* Add FieldDomain metadata producer API for enhanced can_match shard pruning ([#22483](https://github.com/opensearch-project/OpenSearch/pull/22483))
* Add intra-segment search support for histogram, auto_date_histogram, and range aggregations ([#22531](https://github.com/opensearch-project/OpenSearch/pull/22531))
* Add MPP-style distributed join and aggregation execution for the analytics engine ([#21844](https://github.com/opensearch-project/OpenSearch/pull/21844))

### Enhancements

* Add `cluster.blocks.read.auto_release` setting to prevent unconditional auto-release of user-set index read blocks ([#22610](https://github.com/opensearch-project/OpenSearch/pull/22610))
* Add cluster-level remote-store flush settings for uncommitted segments ([#22935](https://github.com/opensearch-project/OpenSearch/pull/22935))
* Restore size-based periodic flush on remote-store shards ([#22865](https://github.com/opensearch-project/OpenSearch/pull/22865))
* Apply `index.periodic_flush_interval` changes to running shards dynamically ([#22991](https://github.com/opensearch-project/OpenSearch/pull/22991))
* Use ordinals instead of byte values for bucket keys in multi-term aggregations ([#21033](https://github.com/opensearch-project/OpenSearch/pull/21033))
* Optimize bucket counting and tracking in LongKeyedBucketOrds with O(1) lookups ([#22450](https://github.com/opensearch-project/OpenSearch/pull/22450))
* Speed up reading history operations from Lucene via sequential stored-fields reader ([#22603](https://github.com/opensearch-project/OpenSearch/pull/22603))
* Use `prefixQuery` to speed up `wildcardQuery` and `regexpQuery` for wildcard field type ([#22510](https://github.com/opensearch-project/OpenSearch/pull/22510))
* Preserve `constant_score` through filtered aliases to maintain Lucene no-scoring fast path ([#22776](https://github.com/opensearch-project/OpenSearch/pull/22776))
* Promote lowest-version replica on document-replication failover to prevent stuck replicas during rolling upgrades ([#22783](https://github.com/opensearch-project/OpenSearch/pull/22783))
* Avoid cancellation checks on every `advance()` call for posting enums to reduce CPU overhead ([#22856](https://github.com/opensearch-project/OpenSearch/pull/22856))
* Avoid quadratic identifier scan when removing snapshots ([#22968](https://github.com/opensearch-project/OpenSearch/pull/22968))
* Stream translog parts instead of buffering the whole file for upload ([#23015](https://github.com/opensearch-project/OpenSearch/pull/23015))
* Change tiered cache default partition count to 16 for improved hit rates on high-core instances ([#23032](https://github.com/opensearch-project/OpenSearch/pull/23032))
* Bound Arrow native memory pools when `node.native_memory.limit` is unknown ([#22762](https://github.com/opensearch-project/OpenSearch/pull/22762))
* Lower default `arrow.flight.channel.outbound_buffer_threshold` from 64 MB to 512 KB ([#22697](https://github.com/opensearch-project/OpenSearch/pull/22697))
* Deprecate `RestHighLevelClient` in favor of `opensearch-java` client ([#23008](https://github.com/opensearch-project/OpenSearch/pull/23008))
* Remove Jackson 2.x dependencies from OpenSearch core ([#22704](https://github.com/opensearch-project/OpenSearch/pull/22704))
* Remove legacy client benchmark and noop API plugin modules ([#21839](https://github.com/opensearch-project/OpenSearch/pull/21839))
* Preserve routing in `Translog.Delete` for CDC-based replication ([#22584](https://github.com/opensearch-project/OpenSearch/pull/22584))
* Exempt server-injected preferences from strict weighted routing check and scope them per index ([#22571](https://github.com/opensearch-project/OpenSearch/pull/22571))
* Reject out-of-range WLM node threshold updates at validation time ([#22649](https://github.com/opensearch-project/OpenSearch/pull/22649))
* Return HTTP 400 for `too_many_clauses` and `too_many_nested_clauses` errors ([#21725](https://github.com/opensearch-project/OpenSearch/pull/21725))
* Refactor `forPattern` if-else chains to switch on `FormatNames` enum for O(1) dispatch ([#22568](https://github.com/opensearch-project/OpenSearch/pull/22568))
* Drain active streams before closing Flight channel to prevent spurious leak errors ([#22642](https://github.com/opensearch-project/OpenSearch/pull/22642))
* Skip stream connections to nodes without a stream address in mixed-version clusters ([#22810](https://github.com/opensearch-project/OpenSearch/pull/22810))
* Remove duplicate native memory limit setting from `NodeDuressSettings` ([#22620](https://github.com/opensearch-project/OpenSearch/pull/22620))
