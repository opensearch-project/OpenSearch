## Version 3.10.0 Release Notes

Compatible with OpenSearch and OpenSearch Dashboards version 3.10.0

### Breaking Changes
* Remove the experimental Views feature ([#23263](https://github.com/opensearch-project/OpenSearch/pull/23263))
* Remove MacOS/x64 archive distributions ([#23160](https://github.com/opensearch-project/OpenSearch/pull/23160))

### Features
* Add `RestoreListenerPlugin` interface, called after a snapshot restore finishes ([#23295](https://github.com/opensearch-project/OpenSearch/pull/23295))
* Add `RoaringOrdinalsCollector` for memory-efficient cardinality aggregation under multi-bucket parents ([#21970](https://github.com/opensearch-project/OpenSearch/pull/21970))
* Add per-node request throttling to workload management ([#22869](https://github.com/opensearch-project/OpenSearch/pull/22869))
* Add cluster-wide shared limit for workload management request throttling ([#23264](https://github.com/opensearch-project/OpenSearch/pull/23264))
* Add `limit` parameter to `_cat` APIs for top-N row limiting ([#23439](https://github.com/opensearch-project/OpenSearch/pull/23439))
* Add cluster setting to enable/disable request and query cache cluster-wide ([#23383](https://github.com/opensearch-project/OpenSearch/pull/23383))
* Add `GET /_cluster/settings/_describe` API to report setting metadata including dynamic flag, defaults, validation bounds, and descriptions ([#23360](https://github.com/opensearch-project/OpenSearch/pull/23360)), ([#23400](https://github.com/opensearch-project/OpenSearch/pull/23400)), ([#23412](https://github.com/opensearch-project/OpenSearch/pull/23412)), ([#23456](https://github.com/opensearch-project/OpenSearch/pull/23456)), ([#23474](https://github.com/opensearch-project/OpenSearch/pull/23474))
* Add administrative route property metadata for REST handlers ([#22979](https://github.com/opensearch-project/OpenSearch/pull/22979))
* Expose registered action names to plugins via `DynamicActionRegistry` ([#23226](https://github.com/opensearch-project/OpenSearch/pull/23226))
* Add pluggable format seams for nested and flat_object field types ([#23121](https://github.com/opensearch-project/OpenSearch/pull/23121))
* Add object store source for pull-based ingestion ([#23339](https://github.com/opensearch-project/OpenSearch/pull/23339))
* Expose caller TLS session on Arrow Flight server channels ([#23465](https://github.com/opensearch-project/OpenSearch/pull/23465))
* Add `IndexModule.addReaderWrapper` to allow composing multiple index reader wrappers ([#23312](https://github.com/opensearch-project/OpenSearch/pull/23312))
* Enable full-copy snapshots for pluggable data format shards ([#23155](https://github.com/opensearch-project/OpenSearch/pull/23155))
* Multi-part parallel download of large segment files from remote store ([#23016](https://github.com/opensearch-project/OpenSearch/pull/23016))
* Support segment replication in `segments_only` remote store mode ([#23098](https://github.com/opensearch-project/OpenSearch/pull/23098))

* Propagate Azure blob existence failures instead of returning false ([#23266](https://github.com/opensearch-project/OpenSearch/pull/23266))
* Extend `getFieldFilter()` contract and make it available via `FieldFilterProvider` and `PluginComponentRegistry` ([#23292](https://github.com/opensearch-project/OpenSearch/pull/23292))

* Resolve primary operation policy on replica promotion ([#23175](https://github.com/opensearch-project/OpenSearch/pull/23175))
* Remove deleted index data left behind by a held shard lock ([#23393](https://github.com/opensearch-project/OpenSearch/pull/23393))
* Prevent stuck snapshot deletes and queue starvation with delete-based recovery ([#23194](https://github.com/opensearch-project/OpenSearch/pull/23194))

* Let a second `./gradlew run` add nodes to the cluster the first one started ([#23221](https://github.com/opensearch-project/OpenSearch/pull/23221))
* Decouple shard snapshots from Lucene `IndexCommit` to support pluggable data formats ([#22930](https://github.com/opensearch-project/OpenSearch/pull/22930))
